# FunPay → Telegram бот уведомлений

Личный помощник продавца FunPay: присылает в Telegram уведомления и сам делает
рутину, пока ты занят чем-то другим.

## Что умеет

- 💬 **Уведомления о новых сообщениях** в чатах FunPay + кнопка «Ответить»:
  отвечай своим текстом или выбирай заготовленный ответ (перед отправкой — подтверждение)
- ✅ Уведомления о подтверждении заказа + **автоответ** покупателю («спасибо за подтверждение»)
- ⭐ Уведомления об отзывах + автоответ на отзывы 4★ и 5★
- 🛒 Уведомления о новых заказах
- ⏰ **Напоминания покупателям** о неподтверждённых заказах (раз в N часов)
- 📨 **Автоматическая заявка в поддержку FunPay**, если заказ не подтверждён больше суток
  (мульти-тикет: все созревшие заказы одной заявкой, с учётом лимита FunPay 1 раз в сутки)
- 🧹 Подсказка удалить пустой лот после продажи
- 📊 `/stats` — баланс, заказы за день/неделю, выручка, самый дорогой заказ
- 🏆 `/top` — продажи по серверам
- 📜 `/logs`, `/status`, `/lots` (массовое изменение цен), `/ban` + чёрный список
- 🚫 Игнор вспомогательных ботов (SellNode/Billy) по имени и по ID

## Как это работает

Бот запускается **на твоём ПК** и крутится в фоне:

1. **FunPay** опрашивается через официальный веб-интерфейс по твоей cookie `golden_key`
   (это твой же браузерный сеанс — никаких паролей от FunPay вводить не надо).
2. **Telegram** подключается по MTProto (как обычный клиент) — VPN не нужен.
   Если прямое подключение не работает (например, вы в регионе с блокировками),
   бот возьмёт MTProto-прокси из настроек или подхватит локальный TgWsProxy, если он запущен.

⚠️ Пока ПК выключен — бот не работает. Если нужен круглосуточный режим, запускай
на VPS/хостинге (папку с ботом можно просто скопировать целиком).

## Установка (Windows)

1. Установи **Python 3.10+** с [python.org](https://www.python.org/downloads/)
   (при установке отметь галочку **Add Python to PATH**).
2. Скачай этот репозиторий (Code → Download ZIP → распакуй).
3. В папке проекта скопируй `.env.example` в `.env` и заполни:

   | Поле | Где взять |
   |---|---|
   | `GOLDEN_KEY` | funpay.com → F12 → Application → Cookies → `golden_key` |
   | `BOT_TOKEN` | Telegram → [@BotFather](https://t.me/BotFather) → /newbot |
   | `TG_USER_ID` | Telegram → [@userinfobot](https://t.me/userinfobot) — твой ID |

4. Открой командную строку в папке проекта и поставь зависимости:

   ```
   pip install -r requirements.txt
   ```

5. Открой в Telegram своего нового бота и нажми **Start** (иначе он не сможет тебе писать).
6. Запусти `start.bat` — в Telegram придёт «🟢 Бот запущен!»

## Запуск и остановка

- `start.bat` — запуск (консоль можно свернуть, не закрывая)
- `stop.bat` — полная остановка

### Автозапуск с Windows (опционально)

`Win+R` → `shell:startup` → положи туда ярлык на `start.bat`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | меню и справка |
| `/stats` | баланс, заказы за сегодня/неделю, выручка |
| `/top` | продажи по серверам (с медианой цен) |
| `/lots` | мои лоты и массовое изменение цен |
| `/presets` | показать заготовленные ответы покупателям |
| `/logs` | последние события |
| `/status` | статус FunPay-аккаунта |
| `/ban ник` / `/bans` | чёрный список покупателей |
| `/cancel` | отменить ввод ответа/цены |

## Настройки `.env` (по желанию)

Все настройки живут в `.env` и подписаны комментариями. Основные:

- `REQUESTS_DELAY` — частота опроса FunPay (сек), минимум 4
- `REMINDER_TEXT` / `REMINDER_INTERVAL_HOURS` — напоминания покупателям
- `SUPPORT_TEXT` / `SUPPORT_CONFIRM_HOURS` — авто-заявка в поддержку
- `AUTO_REPLY_CONFIRM` / `AUTO_REPLY_REVIEW` — автоответы (пусто = выключить)
- `BOT_PASSWORD` — если хочешь дать доступ к меню другому человеку

## Безопасность

- `golden_key` — это доступ к твоему FunPay-аккаунту. **Никому не передавай**
  `.env`, `*.session` файлы и не коммить их в репозитории (`.gitignore` уже настроен).
- Бот отвечает на команды только с твоего Telegram ID.
- Файл `bot.session` — сеанс Telegram; удали его, если меняешь токен бота.

## Если что-то не работает

- **«Не могу написать тебе в Telegram»** — открой своего бота и нажми Start.
- **FunPay возвращает 403/капчу** — сессия протухла: перелогинься на FunPay
  и обнови `golden_key`.
- **Telegram не подключается** — впиши рабочий MTProto-прокси в `TG_MTPROXY`
  (формат `host:port:secret`, несколько через `;`).
- Логи пишутся в `logs/bot.log`.
